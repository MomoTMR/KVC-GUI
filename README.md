# Kerio Control VPN Client GUI (PyQt6)

Современный, быстрый и удобный графический интерфейс для управления официальным консольным VPN-клиентом **Kerio Control VPN Client** (`kerio-kvc`) в операционных системах Linux (Debian, Ubuntu, Pop!_OS, Linux Mint и др.).

---

## 🌟 Основные особенности и преимущества

1. **Безопасность и оптимизация прав доступа (pkexec):**
   * Вместо трех отдельных запросов пароля администратора (чтение конфига, запись нового конфига, перезапуск службы), это приложение объединяет все действия в один безопасный Python-скрипт. Пароль `root` запрашивается **ровно 1 раз** при старте или перезапуске подключения.
2. **Отложенная запись конфигурации:**
   * При выборе или сохранении профилей изменения не вносятся в системный `/etc/kerio-kvc.conf` мгновенно. Изменения применяются **строго в момент старта подключения**.
3. **Локальное хранение профилей:**
   * Все ваши профили (сервер, логин, пароль) хранятся в файле `profiles.ini` прямо в директории проекта. Этот файл внесен в `.gitignore` для предотвращения случайной отправки паролей в публичный репозиторий.
4. **Интеграция с системой (systemd & journalctl):**
   * Получение статуса подключения в реальном времени.
   * Журнал службы (последние 50 строк лога `journalctl`) выводится прямо в графическом окне.
   * Удобное сворачивание в системный трей (Tray Icon) с быстрым меню управления.

## 🛠 Развертывание и установка на пустой Linux-системе

Ниже представлена пошаговая инструкция для полной установки «с нуля» на чистую систему (на примере Ubuntu / Pop!_OS / Debian).

### Шаг 1: Установка консольного клиента Kerio Control VPN

GUI является оболочкой для официальной консольной службы `kerio-kvc`. Если она ещё не установлена:

1. Скачайте `.deb` пакет официального клиента с сайта Kerio (или вашего сервера Kerio Control). Например:
   ```bash
   wget https://download.kerio.com/dwn/control/control-9.4.2-6498/kerio-control-vpnclient-9.4.2-6498-linux-amd64.deb
   ```
2. Установите пакет:
   ```bash
   sudo apt update
   sudo apt install ./kerio-control-vpnclient-9.4.2-6498-linux-amd64.deb
   ```
3. Во время установки установщик предложит ввести сервер и имя пользователя. Вы можете ввести любые тестовые данные, так как GUI будет перезаписывать их автоматически при подключении.
4. Убедитесь, что служба добавлена в systemd:
   ```bash
   systemctl status kerio-kvc
   ```

### Шаг 2: Установка системных зависимостей для GUI и Qt6

Для работы графического интерфейса PyQt6 на чистой системе (особенно если это минимальная установка) требуются библиотеки рендеринга и поддержки графики:

```bash
sudo apt update && sudo apt install -y \
    python3-pip \
    python3-venv \
    libegl1 \
    libgl1 \
    libxcb-cursor0 \
    libxkbcommon-x11-0 \
    libdbus-1-3 \
    libfontconfig1 \
    libfreetype6 \
    libxext6 \
    libxrender1 \
    libice6 \
    libsm6
```

---

### Шаг 3: Установка современного менеджера пакетов `uv`

Проект использует передовой, сверхбыстрый менеджер пакетов `uv` от Astral для изоляции окружения и управления зависимостями.

Установите `uv` одной командой:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
*После установки перезапустите терминал или выполните `source $HOME/.local/bin/env`.*

---

### Шаг 4: Клонирование и настройка проекта

1. Клонируйте репозиторий с проектом:
   ```bash
   git clone <url_вашего_репозитория> KVC-GUI
   cd KVC-GUI
   ```
2. Синхронизируйте проект и создайте изолированное виртуальное окружение со всеми зависимостями (PyQt6 и др.) одной командой:
   ```bash
   uv sync
   ```
   *`uv` автоматически создаст папку `.venv` и установит туда строго необходимые пакеты.*

---

### Шаг 5: Создание ярлыка в меню приложений (Desktop Integration)

Чтобы запускать приложение напрямую из меню поиска Pop!_OS / Ubuntu без использования терминала:

1. Скопируйте готовый файл ярлыка в системную папку пользователя:
   ```bash
   mkdir -p ~/.local/share/applications
   cp kerio-kvc-gui.desktop ~/.local/share/applications/kerio-kvc-gui.desktop
   chmod +x ~/.local/share/applications/kerio-kvc-gui.desktop
   ```
2. Готово! Теперь нажмите клавишу **Super** (Windows), начните вводить `Kerio` и запускайте программу кликом мыши.

## 🚀 Способы запуска

### Из меню приложений (рекомендуется)
Просто откройте меню приложений Pop!_OS / GNOME и найдите **Kerio Control VPN Client GUI**.

### Через терминал (с использованием `uv`):
Запуск в активном окне терминала:
```bash
uv run kvc-gui
```

Запуск в фоновом режиме (терминал можно будет сразу закрыть):
```bash
nohup uv run kvc-gui > /dev/null 2>&1 &
```

## 📂 Структура файлов проекта

* **`main.py`** — основной файл приложения на PyQt6.
* **`profiles.ini`** — локальный файл настроек профилей (генерируется при первом сохранении профиля, **добавлен в `.gitignore`**).
* **`kerio-kvc-gui.desktop`** — ярлык для интеграции программы в операционную систему.
* **`pyproject.toml`** — описание проекта, его зависимостей и точки входа (`kvc-gui`).
* **`uv.lock`** — зафиксированные версии пакетов для гарантированной воспроизводимости окружения.
* **`.gitignore`** — правила исключения временных файлов и конфига с паролями (`profiles.ini`) из Git.
